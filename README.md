## 🧰 Core Modules

### 🗑️ Application Uninstall Manager

Organize software removal tasks in a consistent workflow.

- Create a list of applications to remove.
- Record the reason for each removal.
- Track whether the normal uninstaller completed successfully.
- Document any error messages for later troubleshooting.
- Keep a record of applications that should remain installed.

### 📦 Software Inventory Center

Maintain a reference list of software on your system.

- Record application names and versions.
- Categorize utilities, drivers, productivity apps, and games.
- Note installation sources and license details where appropriate.
- Identify applications that need further review.
- Keep records for future maintenance sessions.

### 🔍 Leftover Review Checklist

Plan a careful review after an application is removed.

- Note folders that may require manual inspection.
- Record relevant configuration and preference locations.
- Check whether files are shared with other applications.
- Avoid deleting unfamiliar system files or shared components.
- Document unresolved cleanup issues.

*Actual automatic detection or removal of leftover files depends on the software package and has not been verified.*

### 💾 Backup & Restore Notes

Prepare for changes that could affect your workflow.

- Record important application settings before removal.
- Note license keys and account-based activation requirements.
- Create a restore point when appropriate and supported.
- Back up user-created files separately.
- Document the steps needed to reinstall essential applications.

### 📊 System Maintenance Log

Keep an organized record of maintenance sessions.

- Record the date and purpose of each cleanup.
- Track completed and pending tasks.
- Document errors and troubleshooting steps.
- Compare software inventory records over time.
- Maintain notes for future system recovery.
